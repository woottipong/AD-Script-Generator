# 02: Review Mode ตั้งแต่ต้นจนจบ ด้วยไฟล์ .mp4 และ .srt บนเครื่อง

Status: resolved

Blocked by: 01

อ้างอิง: [spec](../spec.md) หัวข้อ "การตัดสินใจที่ตกลงกันแล้ว", "ขั้นตอนของผู้ใช้" และ "กฎเวลาและการตรวจที่ server"

**What to build:** ผู้ใช้เข้าแอปแล้วเห็นสองโหมดให้เลือก ถ้าเลือก "แก้ไข SRT ที่มีอยู่" ผู้ใช้เลือกวิดีโอ `.mp4` และไฟล์ `.srt` จากเครื่อง แล้วกด "ประมวลผล" ระบบตรวจวิดีโอ อ่าน SRT สแกนเสียง สร้าง Job ของ Review Mode บน server โดยไม่ส่งวิดีโอขึ้น server แล้วเปิด workspace เดิมที่ไม่มีส่วนสร้างบท ผู้ใช้แก้ข้อความแล้วระบบบันทึกอัตโนมัติ และส่งออก SRT ได้ ใบนี้ใช้ได้แค่ไฟล์บนเครื่อง ส่วน URL อยู่ในใบที่ 05

- [x] หน้าแรกมีสองการ์ด "สร้างบทบรรยาย" และ "แก้ไข SRT ที่มีอยู่" Generate Mode ทำงานเหมือนเดิม ปุ่ม "เริ่มงานใหม่" พากลับมาหน้านี้
- [x] ปุ่ม "ประมวลผล" กดได้เมื่อเลือกทั้งวิดีโอและ SRT แล้ว
- [x] ตรวจวิดีโอตามข้อกำหนดของ Review Mode
  - ไม่ตรวจความละเอียดและ codec ภาพ
  - ไม่จำกัดขนาดไฟล์
  - ความยาวไม่เกิน 60 นาที
  - ต้องมีเสียง AAC
- [x] อ่าน SRT ได้ทั้ง UTF-8 ที่มีและไม่มี BOM ถ้าถอดเป็น UTF-8 ไม่ได้ให้ลอง Windows-874 คงข้อความหลายบรรทัดใน cue ไว้ และตัดแท็ก `<i>`, `<b>`, `<u>`, `<font>` ออก ถ้าไฟล์ว่างหรืออ่านไม่ได้ ให้หยุดพร้อมข้อความที่บอกเหตุผล มี unit test ครอบทุกกรณีนี้
- [x] แต่ละ cue กลายเป็น AD Spot ที่ `decision: 'generate'` เวลาเดิมของ cue ใช้เป็น `original_start_ms` และ `original_end_ms` เรียงตามเวลา
- [x] server สร้าง Job ด้วย `mode: 'review'`, `video_source.kind: 'local_file'` และ `srt_source` มี `batches: []` และสถานะ `READY` และไม่มีไฟล์วิดีโอในโฟลเดอร์ของงาน
- [x] ถ้ามีงาน Generate Mode กำลังวิเคราะห์อยู่ การสร้างงาน Review Mode ตอบ 409 และ route ที่ใช้ Gemini ตอบ 409 กับงาน Review Mode
- [x] เพดานของ `waveform.peaksBase64` เป็น 250,000 ตัวอักษรทั้งสองโหมด
- [x] workspace ซ่อนปุ่ม สถานะ คิว batch และคำสั่งทำต่อหรือลองใหม่ของการสร้างบท ส่วนไทม์ไลน์ ช่วงเสียงพูด คลื่นเสียง editor และการส่งออก SRT ทำงานเหมือนเดิม
- [x] แก้ข้อความแล้วบันทึกอัตโนมัติได้ และสถานะการบันทึกตรงกับการตอบรับของ server
- [x] มี integration test สร้างงาน Review Mode ผ่าน HTTP และ browser test ที่จำลอง API ครอบการเลือกโหมดและการซ่อนส่วนสร้างบท
- [x] `docs/API.md`, `docs/agents/system-constraints.md` และ README อธิบายโหมดที่สอง
