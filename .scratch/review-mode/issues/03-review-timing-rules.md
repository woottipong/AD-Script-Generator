# 03: กฎเวลาของ Review Mode

Status: resolved

Blocked by: 02

อ้างอิง: [spec](../spec.md) หัวข้อ "กฎเวลาและการตรวจที่ server"

**What to build:** ใน Review Mode ผู้ใช้ขยับและปรับเวลาของ AD Spot ได้อิสระภายในความยาววิดีโอ ไม่ถูกล็อกในช่วงว่าง แต่ต้องยาวอย่างน้อย 500 ms และไม่ทับบรรทัดข้างเคียง การทับเสียงพูดทำได้ บรรทัดจาก SRT เดิมที่ผิดกฎยังแก้ข้อความและบันทึกได้ จนกว่าผู้ใช้จะเปลี่ยนเวลาของบรรทัดนั้น ส่วน Generate Mode ใช้กฎเดิม

- [x] กฎของ Review Mode อยู่ในที่เดียวกับกฎเวลาเดิม
  - อยู่ในความยาววิดีโอ
  - ยาวอย่างน้อย `MIN_SPOT_DURATION_MS`
  - ไม่ทับบรรทัดข้างเคียง โดยนับเฉพาะบรรทัดที่ decision ไม่ใช่ "ข้าม"
- [x] การลาก Trim และ Move ปุ่ม nudge ±0.2 วินาที และการพิมพ์เวลา ใช้กฎของ Review Mode เมื่อ Job เป็น Review Mode
- [x] ปุ่ม nudge ถูกปิดเมื่อกดแล้วเวลาจะไม่เปลี่ยน
- [x] บรรทัดที่ทับบรรทัดข้างเคียงอยู่ตั้งแต่นำเข้า เมื่อถูกลากหรือ nudge จะถูกดันขอบให้หลุดจากการทับ
- [x] `PATCH` ของ spots ใน Review Mode ตรวจกฎเฉพาะบรรทัดที่ `start_ms` หรือ `end_ms` ต่างจากที่บันทึกล่าสุด การแก้ข้อความหรือ decision อย่างเดียวผ่านเสมอ Generate Mode ใช้การตรวจเดิม
- [x] Unit test ของกฎ Review Mode ครอบ: ยาวเกินวิดีโอ, สั้นกว่า 500 ms, ทับข้างเคียง, ข้างเคียงเป็นบรรทัด "ข้าม", ทับเสียงพูดแต่ยังผ่าน และ clamp ที่ดันออกจากการทับ
- [x] Integration test ครอบ: `PATCH` ที่แก้แค่ข้อความในบรรทัดที่ผิดกฎแล้วผ่าน และ `PATCH` ที่เปลี่ยนเวลาให้ทับข้างเคียงแล้วถูกปฏิเสธ
