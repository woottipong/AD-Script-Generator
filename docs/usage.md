# คู่มือการใช้งาน

ขั้นตอนใช้งานแต่ละโหมด ข้อกำหนดไฟล์ การแก้ไขในหน้าตัดต่อ และคีย์ลัด ส่วนการติดตั้งและการรันอยู่ใน [README](../README.md)

## ข้อกำหนดเบราว์เซอร์และไฟล์

- ใช้ Google Chrome หรือ Microsoft Edge เวอร์ชันล่าสุดบนคอมพิวเตอร์ เบราว์เซอร์ต้องรองรับ WebCodecs `AudioDecoder` (codec `mp4a.40.2`), Web Workers และ WebAssembly หากไม่รองรับ ระบบจะแจ้งเตือนและระงับการตรวจจับเสียง
- **Generate Mode.** MP4 ที่มีวิดีโอ H.264 (`avc1`/`avc3`) และเสียง AAC สูง 480p ยาวไม่เกิน 30 นาที และขนาดไม่เกิน 2,000 MiB ขนาดมาตรฐานคือ 854×480 ความกว้างอื่นรับได้แต่มีคำเตือน หน้าจอแสดงขนาดไฟล์เป็น MB
- **Review Mode.** MP4 ทุกความละเอียดที่มีแทร็กเสียง AAC ยาวไม่เกิน 60 นาที

ระบบตรวจไฟล์ในเบราว์เซอร์และปฏิเสธไฟล์ที่ไม่ผ่านเกณฑ์ก่อนเข้าหน้าตัดต่อ กฎทั้งหมดอยู่ใน [system-constraints.md](agents/system-constraints.md#video-input-and-srt-import)

## รายการงาน (หน้าแรก)

- แสดงตารางงานที่บันทึกไว้ในคอลัมน์ **ชื่องาน**, **โหมด**, **สถานะ**, **ความยาว**, **บทบรรยาย**, **แก้ล่าสุด** และ **การทำงาน** ผู้ใช้กลุ่ม `admin` / `supervisor` ที่มีสิทธิ์ All-Jobs Access จะเห็นคอลัมน์ **เจ้าของ** และตัวกรองเจ้าของ **ทุกคน** / **งานของฉัน** เพิ่ม
- ค้นหาด้วยชื่องานหรือชื่อไฟล์ และกรองโหมดด้วยปุ่ม **ทั้งหมด** / **สร้างบทบรรยาย** / **ตรวจแก้ SRT**
- เรียงตามคอลัมน์ชื่องาน ความยาว บทบรรยาย หรือแก้ล่าสุดได้ ค่าเริ่มต้นเรียงตามแก้ล่าสุด แต่ละหน้าแสดง 25 รายการ
- ขณะมีงานกำลังประมวลผล หน้านี้รีเฟรชสถานะเองทุก 5 วินาที
- เปิดงานที่ `/jobs/<job_id>` จากลิงก์ชื่องานหรือปุ่ม **เปิดงาน** ลบงานหรือไฟล์อัปโหลดที่ยังไม่เสร็จได้หลังยืนยัน การลบย้อนกลับไม่ได้ และงานที่กำลังวิเคราะห์หรือกำลังอัปโหลดลบไม่ได้
- กดโลโก้ที่แถบด้านบน (**กลับรายการงาน**) เพื่อกลับหน้านี้

## เริ่มงานใหม่ (`/new`)

กด **งานใหม่** แล้วเลือกแท็บ **สร้างบทบรรยาย** หรือ **ตรวจแก้ไฟล์ SRT** กำหนด **ชื่องาน** ได้ตั้งแต่ขั้นเลือกไฟล์ และเปลี่ยนได้ทุกเมื่อที่แถบด้านบนของหน้าตัดต่อ ชื่องานยาวได้ถึง 120 ตัวอักษร ค่าเริ่มต้นคือชื่อไฟล์วิดีโอที่ตัดนามสกุลออก

### สร้างบทบรรยาย (Generate Mode)

การเริ่มและทำต่อด้วย Gemini ต้องใช้บัญชีในกลุ่ม Keycloak `admin` หรือ `supervisor` ที่เข้าถึงงานได้ และเซิร์ฟเวอร์ต้องตั้ง `GEMINI_API_KEY` หากปุ่มหลักกดไม่ได้ ให้เปิดรายละเอียดการทำงานเพื่อดูเหตุผล

1. **ตรวจเสียงและเตรียมงาน** ลากหรือเลือกไฟล์ MP4 แล้วกด **เริ่มเตรียมงาน** ระบบตรวจสเปกและตรวจเสียงบนเครื่อง แล้วส่งวิดีโอส่วนละ 8 MiB ไปเก็บบนเซิร์ฟเวอร์ หากบันทึกไม่สำเร็จ กด **ลองบันทึกอีกครั้ง** เพื่อใช้ผลตรวจเสียงเดิม
2. **สร้างบทบรรยายภาพ** เมื่อบันทึกงานสำเร็จและพบช่วงว่าง กด **สร้างบทบรรยายภาพ** อ่านรายละเอียดการส่งวิดีโอให้ Google Gemini และค่าใช้จ่ายที่อาจเกิดขึ้น แล้วกด **เริ่มสร้างบท AI** ระบบวิเคราะห์ทีละชุด 240 วินาที กดสถานะบนแถบด้านบนเพื่อดูคิวและเลือกชุดที่ต้องการตรวจ
3. **หยุดหรือทำต่อ** กด **หยุดการวิเคราะห์** ระบบเก็บผลของคำขอที่กำลังทำงานหากสำเร็จ และคำขอนั้นอาจยังมีค่าใช้จ่าย เมื่อพร้อมให้กด **ทำต่อจากชุดที่ค้าง** แล้วยืนยันการส่งวิดีโอและค่าใช้จ่ายอีกครั้ง ระบบวิเคราะห์เฉพาะชุดที่ยังไม่เสร็จ
4. **ตรวจและส่งออก** เลือกช่วงจากไทม์ไลน์หรือรายการบท แก้ข้อความ ปรับเวลา แล้วส่งออก SRT หากหยุดไว้และยังมีชุดค้าง จะแก้ได้เฉพาะชุดที่เสร็จแล้ว และระบบให้ยืนยันว่าไฟล์ SRT มีเฉพาะบทจากชุดที่เสร็จแล้ว

โควตาเริ่มต้นคือ 3 งานต่อบัญชีต่อวันตามเวลาไทย (`AI_DAILY_JOB_LIMIT`) ระบบนับเมื่อรับคำขอวิเคราะห์ งานเดิมที่เริ่มหรือทำต่อด้วยบัญชีเดิมในวันเดียวกันใช้สิทธิ์เดิม การหยุดงาน รีสตาร์ตเซิร์ฟเวอร์ หรือลบงานไม่คืนโควตา

หากเซิร์ฟเวอร์รีสตาร์ตระหว่างวิเคราะห์ งานจะกลับเป็นสถานะพร้อมวิเคราะห์ ให้เปิดงานเดิมแล้วกด **ทำต่อจากชุดที่ค้าง** การสแกนเสียงใหม่จะแทนข้อความและเวลาที่แก้ไว้

### ตรวจแก้ไฟล์ SRT (Review Mode)

- เลือกวิดีโอ MP4 จากเครื่องหรือวางลิงก์ `.mp4` ลิงก์ต้องอนุญาต CORS ให้เบราว์เซอร์อ่านได้และรองรับ HTTP Range
- เลือกไฟล์ `.srt` แบบ UTF-8 หรือ Windows-874 จากเครื่อง หรือวางลิงก์ Google Drive ที่เปิดสาธารณะ แล้วกด **เริ่มตรวจแก้**
- ระบบสแกนเสียงพูดและเล่นวิดีโอบนเครื่องโดยไม่ส่งวิดีโอขึ้นเซิร์ฟเวอร์และไม่ใช้ Gemini ส่วนเมทาดาตางานและบทที่แก้บันทึกบนเซิร์ฟเวอร์
- เปิดงานกลับมาใหม่ไม่ต้องสแกนเสียงซ้ำ วิดีโอจากลิงก์เล่นต่อได้ทันที วิดีโอจากไฟล์บนเครื่องต้องเลือกไฟล์เดิม (ชื่อและขนาดตรงกัน) อีกครั้งก่อนเล่น ระหว่างนั้นยังแก้บทและส่งออกได้

## การแก้ไขในหน้าตัดต่อ

- Generate Mode: เวลาเริ่มและจบต้องอยู่ในช่วงว่างต้นทาง ไม่ทับเสียงพูด และยาวอย่างน้อย 500 ms ส่วน Review Mode ปรับเวลาได้ตามความยาววิดีโอและช่วงข้างเคียง โดยการทับเสียงพูดแสดงเป็นคำเตือน ดู [กฎการแก้เวลา](agents/system-constraints.md#editing-and-validation-rules)
- หาก AI เลือก **ข้าม** ให้กด **บรรยาย** เพื่อเปิดใช้ช่วงนั้น ระบบใช้บทเดิมถ้ามี หรือใช้เหตุผลของการข้ามเป็นข้อความตั้งต้น การสลับกลับไปข้ามไม่ลบบทเดิม
- ช่องค้นหา (ปุ่ม `×` **ล้างคำค้นหา**), ตัวกรอง และปุ่ม **ต้องตรวจ** อยู่แถวบนสุดของรายการบท
- **ต้องตรวจ** นับบรรทัดที่ควรดูก่อนส่งออก แยกตามชนิด กดชนิดใดเพื่อไปบรรทัดถัดไปของชนิดนั้น Review Mode นับบรรทัดที่ทับเสียงพูด ทับบรรทัดอื่น สั้นกว่า 0.5 วินาที หรือเลยท้ายวิดีโอ ทั้งสองโหมดนับบรรทัดที่ข้อความน่าจะพูดนานกว่าช่วงเป็นข้อมูลประกอบ เพราะ Extended AD ที่หยุดภาพระหว่างบรรยายใช้ช่วงยาวกว่าได้ คำเตือนทุกข้อไม่ขวางการบันทึกหรือส่งออก
- งานที่สร้างบนเซิร์ฟเวอร์บันทึกข้อความ สถานะ และเวลาอัตโนมัติ ข้อความ **บันทึกบนเซิร์ฟเวอร์แล้ว** แสดงหลังเซิร์ฟเวอร์ตอบรับ หากบันทึกไม่สำเร็จ ระบบเก็บสิ่งที่แก้ในหน้านั้นและมีปุ่มลองบันทึกอีกครั้ง งานที่ยังไม่สร้างบนเซิร์ฟเวอร์อยู่ในหน้านั้นเท่านั้น ปิดหรือโหลดหน้าใหม่แล้วข้อมูลหาย
- เมนู **จัดการงาน** ใน Generate Mode มีคำสั่งเปลี่ยนวิดีโอ เริ่มงานใหม่ สแกนเสียงใหม่ **ส่งออก SRT** และ **สร้างบทบรรยายใหม่** คำสั่งสแกนเสียงใหม่ใช้ได้เมื่อหน้านั้นยังมีไฟล์ต้นทาง และ **ส่งออก SRT** อยู่ในเมนูเมื่อปุ่มหลักเป็นปุ่มเริ่มหรือทำต่อการสร้างบท Review Mode มีเฉพาะเริ่มงานใหม่ การสแกนใหม่หรือสร้างบทใหม่อาจแทนข้อความและเวลาที่แก้ไว้
- เริ่มงานใหม่แค่ออกจากงานปัจจุบัน ไม่ลบงานหรือวิดีโอที่บันทึกไว้ และไม่ยกเลิกงานเบื้องหลัง หากเปลี่ยนวิดีโอหรือเริ่มงานใหม่ระหว่างอัปโหลด ผลตอบกลับของงานเดิมจะไม่เปลี่ยนหน้าจองานใหม่ และงานที่เซิร์ฟเวอร์เริ่มประมวลผลแล้วอาจทำต่อจนเสร็จ

## คีย์ลัดบนหน้าตัดต่อ

| คีย์ | การทำงาน |
|---|---|
| `Alt + ArrowUp` / `Alt + ArrowDown` | เลือกช่วงบรรยายก่อนหน้า / ถัดไป |
| `Alt + P` | เล่นหรือหยุดวิดีโอ หากตำแหน่งอยู่นอกช่วงที่เลือก ระบบเริ่มเล่นจากช่วงนั้น วิดีโอเล่นต่อเมื่อพ้นช่วง เว้นแต่เปิดวนซ้ำ |
| `Space` / `Enter` บนจอวิดีโอ | เล่นหรือหยุดวิดีโอ |
| `Space` / `Enter` บนช่วงบรรยายในไทม์ไลน์ | เลือกช่วงนั้นและเลื่อนเวลาไปจุดเริ่มต้นของช่วง |
| `ArrowLeft` / `ArrowRight` บนแถบเลื่อนเวลา | เลื่อนเวลาครั้งละ 1 วินาที (`Home` ไปต้นวิดีโอ, `End` ไปท้ายวิดีโอ) |

## ไฟล์ส่งออก

ไฟล์ส่งออกเป็น SubRip (`.srt`) ที่มีเฉพาะช่วงที่เลือกบรรยายและมีข้อความ เรียงตามเวลา Generate Mode ตั้งชื่อไฟล์เป็น `<ชื่อไฟล์วิดีโอ>_thai_ad.srt` ส่วน Review Mode ตั้งเป็น `<ชื่อ SRT เดิม>_edited.srt`

ตรวจผลกับวิดีโอต้นฉบับก่อนนำไปใช้งาน
