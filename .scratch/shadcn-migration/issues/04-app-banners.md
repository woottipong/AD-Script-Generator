# 04: แถบเตือนและหน้าไม่พบงานใน App

Status: ready-for-agent

Blocked by: 01

อ้างอิง: [spec](../spec.md) แถว `App.tsx` และ DESIGN.md › Don't (ห้ามแถบเต็มความกว้างที่ดันวิดีโอ)

**What to build:** แถบ "มีงานวิเคราะห์ที่ยังไม่เสร็จ", "เลือกวิดีโอเดิมอีกครั้ง" และ "ไม่ได้นำเข้า N บรรทัดจาก SRT" กับหน้า "ไม่พบงานนี้ / เปิดงานไม่สำเร็จ" ใช้ component ของ shadcn ตำแหน่งและพื้นที่ที่ใช้เท่าเดิม

- [ ] แถบเตือนเป็น `Alert` variant `warning` แบบเต็มความกว้างใต้ navbar เหมือนเดิม รายการบรรทัดที่ไม่ได้นำเข้าใช้ `Collapsible` แทน `<details>`
- [ ] ปุ่ม "เลือกวิดีโอเดิม" เป็น `Button` outline ที่เปิดตัวเลือกไฟล์ และยังตรวจชื่อและขนาดไฟล์เหมือนเดิม
- [ ] หน้าไม่พบงานและหน้าเปิดงานไม่สำเร็จใช้ `Empty` พร้อมปุ่มกลับรายการงาน ส่วนตอนกำลังเปิดงานใช้ `Skeleton` หรือ `Spinner` แทนข้อความล้วน
- [ ] ไม่เหลือ `.banner-warning` ใน `App.tsx`
- [ ] `review-restore.js` และ `job-list.js` ผ่าน
