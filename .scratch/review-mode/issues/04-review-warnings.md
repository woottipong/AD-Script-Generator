# 04: คำเตือนบรรทัดที่มีปัญหาใน Review Mode

Status: ready-for-agent

Blocked by: 03

อ้างอิง: [spec](../spec.md) หัวข้อ "การตัดสินใจที่ตกลงกันแล้ว" (บรรทัดที่ไม่ตรงวิดีโอ และทับเสียงพูด) และ "ขั้นตอนของผู้ใช้" ข้อ 5

**What to build:** ผู้ตรวจบทเห็นทันทีว่าบรรทัดไหนใน SRT มีปัญหา และไล่แก้ได้ทีละบรรทัด คำเตือนไม่บังคับแก้ บันทึกและส่งออกได้เสมอ

- [ ] บรรทัดที่ทับ Speech Segment, ทับบรรทัดข้างเคียง หรือสั้นกว่า 500 ms ถูกไฮไลต์ทั้งในรายการและบนไทม์ไลน์ พร้อมบอกประเภทของปัญหา
- [ ] คำเตือนใช้กฎชุดเดียวกับใบที่ 03 ไม่คำนวณกฎซ้ำอีกชุด
- [ ] แสดงจำนวนบรรทัดที่มีคำเตือน และมีตัวกรอง "เฉพาะบรรทัดที่มีคำเตือน"
- [ ] คำเตือนหายไปทันทีเมื่อผู้ใช้แก้จนบรรทัดนั้นไม่มีปัญหาแล้ว
- [ ] ตอนนำเข้า บรรทัดที่เริ่มเลยความยาววิดีโอไม่ถูกนำเข้า และผู้ใช้เห็นรายการบรรทัดเหล่านั้นพร้อมเวลา
- [ ] Generate Mode ไม่แสดงคำเตือนเหล่านี้
- [ ] มี unit test ของการตรวจหาปัญหาแต่ละประเภท และ browser test ที่จำลอง API ครอบการแสดงจำนวนกับตัวกรอง
