# Triage labels

Use these canonical roles as the `Status:` values in local issue files:

| Role | Status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Wayfinding tickets use `claimed` and `resolved` for their separate lifecycle, as described in `issue-tracker.md`.
