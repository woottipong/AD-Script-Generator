# 06: เปิดงาน Review Mode เดิมหลังรีเฟรช

Status: resolved

Blocked by: 02, 05

อ้างอิง: [spec](../spec.md) หัวข้อ "การตัดสินใจที่ตกลงกันแล้ว" (เปิดงานเดิม) และ [ADR-0002](../../../docs/adr/0002-job-mode-and-video-source.md) หัวข้อ Consequences

**What to build:** เมื่อผู้ใช้รีเฟรชหน้าระหว่างทำงาน Review Mode งานที่ active อยู่กลับมาเหมือน Generate Mode ทั้งช่วงบรรยาย การแก้ที่บันทึกแล้ว ผลสแกนเสียง และคลื่นเสียง โดยไม่ต้องสแกนเสียงใหม่ ถ้าวิดีโอมาจาก URL ก็เล่นต่อได้ทันที ถ้ามาจากไฟล์บนเครื่อง ระบบขอให้เลือกไฟล์เดิมอีกครั้งก่อนเล่น

- [x] งาน Review Mode ที่ active ถูกเปิดกลับมาตอนรีเฟรช ใน workspace ที่ซ่อนส่วนสร้างบท
- [x] ถ้า `video_source.kind` เป็น `url` วิดีโอเล่นจาก URL ที่บันทึกไว้ได้ทันที
- [x] ถ้า `video_source.kind` เป็น `local_file` ระบบแสดงชื่อไฟล์เดิมและขอให้เลือกไฟล์อีกครั้ง ถ้าชื่อหรือขนาดไม่ตรงกับที่บันทึกไว้ ให้ปฏิเสธพร้อมบอกเหตุผล ระหว่างรอเลือกไฟล์ ผู้ใช้ยังแก้ข้อความและส่งออก SRT ได้
- [x] ไม่สแกนเสียงซ้ำ ใช้ `vad_output` ที่บันทึกไว้
- [x] มี browser test ที่จำลอง API ครอบการเปิดงานทั้งสองแบบ รวมถึงกรณีที่เลือกไฟล์ผิด
